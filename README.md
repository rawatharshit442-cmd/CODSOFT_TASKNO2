# PhishSafe — CodSoft Task 2: Phishing Awareness Program

A web-based educational training module for the CodSoft Cyber Security Internship Task 2.

## Requirements covered
- Educational module about phishing attacks
- Suspicious emails, fake login pages and fraudulent websites
- Common social-engineering techniques
- Practical security tips
- Case studies / real-life scenarios
- Interactive short quiz

## Run
No installation is required. Open `index.html` in a browser. VS Code Live Server can also be used.

## Structure
- `index.html` — training content and quiz interface
- `style.css` — responsive design
- `script.js` — quiz logic
- `README.md` — documentation
- `LICENSE` — MIT license
